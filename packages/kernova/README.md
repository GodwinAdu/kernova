# kernova

[![npm version](https://img.shields.io/npm/v/kernova.svg)](https://www.npmjs.com/package/kernova)
[![license](https://img.shields.io/npm/l/kernova.svg)](https://github.com/GodwinAdu/kernova/blob/main/LICENSE)

**The `kernova` command, under its shortest name.**

This package is an alias for [`@kernova/cli`](https://www.npmjs.com/package/@kernova/cli), so you can run the Kernova CLI without typing the scope:

```bash
npx kernova create my-app
npx kernova doctor
```

or install it globally:

```bash
npm install -g kernova
kernova --help
```

It always runs the `@kernova/cli` version it depends on, and has no code of its own.

**[Documentation](https://kernova2026.vercel.app)** · [CLI reference](https://kernova2026.vercel.app/framework/cli-reference/) · [GitHub](https://github.com/GodwinAdu/kernova)

Starting a new project? Use [`create-kernova-app`](https://www.npmjs.com/package/create-kernova-app):

```bash
npx create-kernova-app my-app
```
