# @nexus/types

Type definitions for the Nexus Intelligent Systems Runtime.

Defines the Universal Object Model: Intent, Agent, Event, Memory, Workflow, Identity, Model, and Streaming types.

## Installation

```bash
npm install @nexus/types
```

## Usage

```typescript
import type { Intent, AgentDefinition, NexusEvent, MemoryEntry } from '@nexus/types';
```

Zero runtime dependencies. Types only.
